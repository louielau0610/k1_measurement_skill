# Terminology Consistency Table

| preferred_term | allowed_variants | discouraged_variants | definition | sections_to_use | notes |
| --- | --- | --- | --- | --- | --- |
| artifact-governed pipeline | offline artifact-governed pipeline, five-stage pipeline | automated pipeline, validated pipeline | A manually-structured, script-driven research pipeline where each stage produces traceable output artifacts with validation steps. | §1, §3, §4, §5 | Avoid "automated" — pipeline requires manual execution of producer scripts. |
| black-box command-to-motion response modeling | deployment-layer response characterization, black-box command-response calibration | system identification (when unqualified), controller modeling | The process of measuring commanded vs. actual robot motion externally, without access to internal controller parameters. | §1, §2, §3, §5 | "System identification" usually implies internal model access; qualify as "external/deployment-layer" if used. |
| closed-source legged robot deployment | SDK-driven robot, black-box robot platform | proprietary robot (too vague) | A legged robot operated through a manufacturer-provided SDK command interface without internal controller or policy access. | §1, §2, §3, §5 | Consistent with K1 platform characterization. |
| velocity response dataset | Dataset v1, velocity response dataset v1 | measurement dataset (ambiguous), raw data | A schema-valid JSON dataset of command-response records derived from Measurement v0 artifacts. | §3, §4 | Always use "Dataset v1" or full name. |
| uncertainty-aware response model foundation | response model, M15R model, uncertainty_aware_hybrid_v1 | learned model, ML model, predictive model | A lightweight, rule-based model that produces conservative velocity response predictions with categorical uncertainty/confidence labels. | §3, §4, §5 | Not a learned/ML model. Emphasize "rule-based" and "conservative." |
| categorical uncertainty label | uncertainty label, confidence label, reliability marker | calibrated uncertainty, probability estimate, confidence score | A categorical reliability flag (low/medium/high/extreme) assigned to each prediction, not a calibrated probability. | §3, §4, §5, §6 | Always clarify "categorical, not calibrated probability." |
| advisory navigation-risk mapping | navigation risk assessment, advisory risk map, risk mapping layer | safety controller, risk-based navigation control | An offline process that translates response predictions into advisory risk categories and warning metadata without controlling the robot. | §3, §4, §5, §6 | Never imply control or safety guarantee. |
| structural validation | structural/software validation, artifact validation, pipeline validation | performance validation, experimental validation | Verification that pipeline artifacts exist, conform to schema, and are reproducible via scripts — not evaluation of real-world performance. | §4, §5, §6 | Always separate from "performance validation." |
| claim-governed evaluation | claim governance, claim-managed evaluation, evidence-governed reporting | paper-ready evaluation, publication evaluation | An evaluation approach that tracks supported claims, candidate contributions, and prohibited claims through registry/evidence/non-claims artifacts. | §3, §4, §5 | Not "publication-ready." |
| non-claim | unsupported claim, prohibited claim | negative result, failure | A statement that the project must not assert as established, tracked in `paper/claims/non_claims.md`. | §4, §5, §6 | Specific governance term; use consistently. |
