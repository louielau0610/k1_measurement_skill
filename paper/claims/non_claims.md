# Non-Claims

The project must not state these as established claims:

- Low-speed deadzone is solved.
- Velocity compensation is implemented in `k1_measurement_skill`.
- Navigation control is implemented in `k1_measurement_skill`.
- The method outperforms baselines.
- The method is novel without a verified literature comparison.
- The current velocity profile is universal across floors, sessions, or K1 units.
- The current pipeline proves real navigation safety improvement.
- The current pipeline proves collision-rate reduction.
- The current pipeline proves near-miss-rate reduction.
- The current pipeline proves navigation success-rate improvement.
- The current pipeline is ready for full publication submission.
- The current pipeline is compensation-ready.
- The current pipeline is safe-command-adapter-ready.
