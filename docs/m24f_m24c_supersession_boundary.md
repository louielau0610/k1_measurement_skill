# M24-F M24-C Supersession Boundary

M24-E identified the M24-B/M24-C extraction method as faulty. M24-F therefore supersedes the M24-C decision and M24-C candidate profile with corrected extraction artifacts.

The M24-C artifacts are retained for traceability. They should not be used as current S2 profile evidence, and `outputs/compensation_experiments/m24c_s2_current_profile_candidate.json` must not be treated as adopted.

Use these M24-F artifacts for corrected review instead:

- `outputs/compensation_experiments/m24f_corrected_s2_profile_refresh_summary.json`
- `outputs/compensation_experiments/m24f_corrected_s2_current_profile_candidate.json`
- `outputs/compensation_experiments/m24f_supersession_notice.json`

The corrected M24-F candidate remains a candidate only. Because the corrected analysis is `corrected_analysis_inconclusive`, the K1 gold profile remains unchanged and a controlled review or replication step is still required before any profile adoption or compensation validation.
