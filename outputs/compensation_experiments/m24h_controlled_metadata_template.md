# M24-H Controlled Metadata Template

Fill this template during the controlled S2 replication session. Copy to the robot and edit before/between trials.

## Required Fields

| Field | How to Fill |
|-------|-------------|
| `session_id` | Auto-generated by runner, or set via `--session-id` |
| `surface` | Must be `S2_marble_floor` |
| `robot_id` | Operator-visible robot identifier (e.g., `Booster_K1`) |
| `warmup_status` | `completed`, `not_completed`, or `unknown` |
| `start_pose_label` | Marked start pose used for every trial |
| `path_label` | Marked straight path used for every trial |
| `operator_reset_required` | Must be `true` |
| `reset_confirmation_required` | Must be `true` |
| `extraction_window_method` | `command_phase_with_1s_trim` |

## Optional Fields

| Field | How to Fill |
|-------|-------------|
| `firmware_or_software_notes` | Fill if version info is available on robot |
| `battery_level_start` | Battery % at session start |
| `battery_level_end` | Battery % at session end |
| `path_length_m` | Approximate path length if known |
| `notes` | Any session-level notes |

## Boundary

- Missing optional fields should be left as empty strings — do NOT fabricate values.
- Required fields must be filled. If a required field is unavailable, document it in `notes` and the trial may need review.
