## Workflow

1. Define target question and scope.
2. Search source hierarchy.
3. Verify citation metadata.
4. Add or update literature matrix rows.
5. Create detailed notes for important papers.
6. Update claim registry.
7. Separate manuscript-ready claims from hypotheses.
8. Run final quality checks.

## Final Checks

- No fabricated citation.
- No unsupported novelty claim.
- No invented experiment result.
- No unverified DOI / arXiv / venue.
- Project evidence and literature evidence are separated.
